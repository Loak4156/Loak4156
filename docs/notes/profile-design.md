# Profile design — 2026-10-27

The profile uses a repository-owned SVG banner, GitHub-supported Markdown/HTML, and four optional Shields.io credential badges. Core identity and credential names remain available as text if images fail. No JavaScript, remote fonts, or dynamic statistics services are required.

Facts were retained from the previous README; the employer is from the public repository description. Do not infer certification level or validity from the ISO/IEC 27001:2022 label: the original profile does not specify either. Owner clarification remains useful before making a more specific claim.

The public account currently exposes only its profile repository. Do not link private project repositories or production/internal endpoints. Add public project links when the owner makes them available.

The previous hero depended on a third-party typing SVG; this dependency has been removed. Shields.io remains an optional external dependency with a plain-text fallback.
